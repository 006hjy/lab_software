# 串口转发工具 (com_capture)

连接两个串口并双向转发数据：任一串口收到的字节会立即转发到另一个串口，同时在界面下方记录通讯方向和数据内容。

## 功能

- 选择两个串口（可手动输入端口名并刷新列表）。
- 波特率可修改，默认 `9600`。
- 双向实时转发（数据不缓存、不做处理）。
- 通讯记录按方向显示：`串口1 → 串口2`（蓝色）、`串口2 → 串口1`（绿色），同时给出时间、字节数、HEX 和 ASCII 内容。
- 连续 80ms 内无新数据的字节流会被合并为一条记录，便于阅读。
- 支持清空记录、暂停/恢复自动滚动，并显示两个方向的累计字节数。

## 使用

1. 启动程序，选择串口 1、串口 2，确认波特率。
2. 点击“开始转发”，两个串口打开后即开始双向转发。
3. 下方“通讯记录”中查看方向和内容；结束后点击“停止转发”或直接关闭窗口。

## 构建

使用 Visual Studio 打开 `lab_software.slnx`，或运行：

```
MSBuild.exe com_capture\com_capture.csproj /p:Configuration=Release
```

输出：`com_capture\bin\Release\com_capture.exe`
